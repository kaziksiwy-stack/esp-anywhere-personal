# Quick start

Install through HACS, add the integration with the one-time HA code supplied by the administrator, then open Configure.

Choose Add device, enter a friendly name, select ESP32-C3-DevKitM-1, confirm the generated ID, and open the short-lived provisioning address. In desktop Chrome or Edge connect a USB data cable, flash, enter Wi-Fi, and wait until every stage is green. The ESP appears in the existing HA entry automatically.

The normal flow never asks for ADMIN_TOKEN, installation ID, config.h, Git, PlatformIO or terminal commands.
